# CHIKAYA AI — Phase 1

A dark, responsive, multilingual landing page for a Moroccan customer-support SaaS platform.

## Included
- Next.js App Router + TypeScript
- Dark premium visual identity
- Language switcher: English, French, Arabic
- RTL layout for Arabic
- Responsive desktop and mobile layouts
- Landing sections: hero, product preview, features, workflow, languages, CTA

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build check
```bash
npm run build
```
